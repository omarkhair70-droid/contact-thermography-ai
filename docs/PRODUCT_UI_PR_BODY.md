# Lane B — Client demo product UI

This branch converts the technical dashboard into a client-demo examination workflow while preserving research/reference semantics.

Highlights:
- Dashboard / New Exam / History / Reference navigation.
- Drag/drop multi-image upload and friendly LEFT/RIGHT/POSITION assignment.
- TLC/device profile provenance.
- Original + response mask + QC + reference-AI finding cards.
- Bilateral panel/difference/aligned image review.
- Saved examination detail and refreshed client-facing report.
- Responsive desktop/tablet/mobile layout.
